Make the Legacy Widget block available anywhere in the WordPress block editor.

== Description ==

Moving to a full FSE theme but still need a classic widget? Want a legacy widget in a Post, Page, Pattern or Template?

This plugin makes the Legacy Widget block available anywhere in the WordPress block editor. It simply bundles the code from [Using the Legacy Widget block in other block editors (Advanced)](https://developer.wordpress.org/block-editor/how-to-guides/widgets/legacy-widget-block/#using-the-legacy-widget-block-in-other-block-editors-advanced) in a light-weight plugin.

No options, just install and active, then find and add a Legacy Widget block in your Site Editor or Post Editor.
